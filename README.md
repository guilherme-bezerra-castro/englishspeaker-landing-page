# English Speaker

Landing page desenvolvida para uma escola de inglês fictícia como projeto da disciplina de Desenvolvimento Front-End durante o primeiro semestre do curso de Análise e Desenvolvimento de Sistemas.

O projeto foi construído utilizando apenas HTML5, CSS3 e JavaScript puro, com foco na implementação das funcionalidades solicitadas pela disciplina, organização do código e aplicação dos fundamentos do desenvolvimento web.

## Demonstração

**Acesse a aplicação:**

https://guilherme-bezerra-castro.github.io/englishspeaker-landing-page/

## Tecnologias

- **HTML5** — estrutura semântica da página
- **CSS3** — estilização e responsividade
- **JavaScript** — interatividade da interface

## Funcionalidades

- Página inicial institucional
- Menu de navegação
- Seções de apresentação da escola
- Informações sobre cursos oferecidos
- Área de diferenciais da instituição
- Formulário de contato
- Layout responsivo para diferentes dispositivos

## Objetivo

Este projeto teve como objetivo aplicar os conceitos fundamentais de desenvolvimento front-end estudados durante o primeiro semestre da graduação, incluindo:

- Estruturação semântica utilizando HTML5;
- Estilização com CSS3;
- Manipulação do DOM com JavaScript;
- Organização de arquivos e diretórios;
- Construção de interfaces web responsivas.

> **Observação:** Como projeto acadêmico introdutório, o foco principal foi a implementação das funcionalidades propostas pela disciplina, priorizando aspectos técnicos e estruturais em vez de refinamentos avançados de design.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/guilherme-bezerra-castro/englishspeaker-landing-page.git
```

Entre na pasta do projeto:

```bash
cd englishspeaker-landing-page
```

Abra o arquivo `index.html` em qualquer navegador moderno.
